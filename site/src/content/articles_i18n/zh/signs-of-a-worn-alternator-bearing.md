发电机是附件传动上转得最快的部件:它的皮带轮比曲轴皮带轮小两到三
倍,所以转子每分钟能转到几万转。它靠两个滚动轴承支撑,一旦磨损,
发电机就成了机舱异响的头号来源。好消息是:这些声音有可辨认的特
征,而且不用拆任何东西就能验证怀疑。

## 发电机轴承为什么会磨损

加速磨损的原因有好几个,而且几乎都来自外部。皮带张力以恒定的侧向
载荷压在转子轴上——皮带张得过紧,前轴承的负荷成倍增加。下方,发
电机接住路上的水和泥:涉深水坑和高压冲洗发动机会把润滑脂冲走。上
方,排气歧管烤着它——高温让油脂变稀、老化得更快。

再加上曲轴转动不均匀带来的皮带冲击,本来应该由单向减震皮带轮吸
收;而磨损的减震轮反其道而行之,把冲击直接送到轴上。所以减震轮和
轴承的状态是直接挂钩的。

## 磨损听起来是什么样

声音是分阶段发展的,每个阶段都抓得住:

1. **冷车时的细尖啸叫。** 起动后头几分钟,热起来就消失——润滑脂
   变稠,没能覆盖滚道。皮带打滑的声音很像,区别见症状页
   [皮带尖叫](/zh/symptoms/belt-squeal/)。
2. **随转速升高的啸叫。** 最好辨认的阶段:一种有音调的声音,轰油
   门时音调跟着爬升,打开大灯和后窗加热后明显变响——用电负荷会把
   转子压得更紧。
3. **任何转速下的嗡鸣和轰响。** 滚道已经坏了;怠速和行驶中都有,
   而且不跟着车速走。
4. **摩擦声和金属沙沙声。** 保持架正在解体——离卡死只剩几趟车程。

每个阶段的关键标志:声音跟着发动机转速走,而不是车速,并且转弯时
不变化——这一点和轮毂轴承不同。具体车型的例子见
[雪佛兰科鲁兹:发电机轴承啸叫](/zh/articles/chevrolet-cruze-alternator-bearing-whine/)。

## 不拆车怎么检查

在自家车库能做的四种方法:

- **负载测试。** 怠速状态下打开远光、后窗加热和鼓风机。啸叫变响,
  就是指向发电机的有力证据。
- **听诊器。** 发动机运转时把探头顶在发电机壳体上——磨损的轴承一
  听就出来。用一根长螺丝刀、手柄贴着耳朵也行;注意躲开转动件。自
  制版本见
  [自己动手做汽车听诊器](/zh/articles/diy-mechanics-stethoscope/)。
- **不装皮带起动。** 把多楔带卸下来短暂起动一下:声音没了,说明是
  附件的问题;声音还在,就得往发动机内部找。
- **检查旷量。** 熄火状态下,用手横向晃动发电机皮带轮:能感觉到旷
  量或者磕碰感,说明轴承已经坏了。

## 容易和什么弄混

| 表现 | 发电机轴承 | 单向减震皮带轮 | 皮带张紧轮 | 水泵 |
|---|---|---|---|---|
| 对开灯、开加热的反应 | 变响 | 无 | 无 | 无 |
| 起动和熄火瞬间的啸叫 | 少见 | 典型 | 有可能 | 有可能 |
| 熄火后的咔啦声 | 无 | 典型 | 无 | 无 |
| 有防冻液渗漏 | 无 | 无 | 无 | 典型 |

嗡鸣同时伴有防冻液痕迹,就该查水泵;这两个部件之间怎么分,见
[机舱里的啸叫:发电机还是水泵](/zh/articles/alternator-or-water-pump-whine/)。

## 修理方案怎么定

发电机轴承属于易损件,换轴承比换整个发电机划算得多;一台新发电机
的价格是大修的好几倍,所以返修是常规做法。

同意开工之前值得问这几句。既然发电机已经拆下来、工时都付了,还有
什么可以顺手一起做——碳刷、调节器、单向减震皮带轮。有没有检查皮
带张紧度,因为张得过紧正是弄坏旧轴承的原因,也会照样弄坏新的。以
及发电机自己的散热风道通不通:被泥堵住的机器温度更高,会把润滑脂
烤干。

有一个理由说明不能拖:轴承一旦卡死,整条皮带传动就停了。车立刻失
去充电,很多发动机上还会同时失去水泵和助力转向。本来是一次预约好
的维修,变成了叫拖车。
