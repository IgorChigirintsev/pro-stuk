比如时速七十公里时冒出一阵啸叫，持续几百米，再加把油又没了——这种声音
听着太怪，很多司机干脆归咎于路面。其实这种对车速的挑剔不是偶然，而是
机构留下的签名：齿面或者轴上的轴承磨损后，齿轮传动就是这么表现的。下
面说说声音为什么跟一小段车速绑定，以及怎么把变速箱和轮毂、轮胎分开。

## 啸叫为什么跟车速绑定

每一对齿轮转动时都会以自己的啮合频率发声——由齿数和轴转速决定。齿面还
光滑的时候，这个频率只是安静的背景。一旦磨损、划伤，或者轴承松旷，它
就会被放大很多倍。

接下来车身也掺和进来。每个车身都有自己的共振频率；当啮合频率跟其中之
一重合时，钣金件就跟着一起唱，啸叫在车厢里就变得很清楚。继续加速，频
率越过共振点，声音就掉下去了。所以才有那种“只在七十公里啸”的感觉。这
也解释了为什么换个挡，那段车速窗口往往就挪了位置：轴的转速变了，重合
点也跟着变。

## 怎么把变速箱和其他来源区分开

| 来源 | 跟挡位有关吗 | 跟转弯有关吗 | 跟着油门变吗 |
|---|---|---|---|
| 变速箱齿轮 | 有，窗口会挪 | 无 | 明显有 |
| 主减速器、差速器 | 弱相关 | 无 | 有，给油和滑行不一样 |
| 轮毂轴承 | 无 | 有，弯中变大 | 无 |
| 轮胎 | 无 | 弱相关 | 无，取决于路面 |
| 传动轴支撑、半轴 | 无 | 略有 | 中等 |

关键的检查有两个：换挡和收油滑行。如果时速七十公里时从四挡换到三挡，
啸叫的音高变了或者位置挪了，那声源就在变速箱里转着。如果松油门后声音
的性质明显变化，说明它取决于齿面上的负荷——同样是传动系。路面噪音的总
体目录在症状页
[行驶中的嗡鸣](/zh/symptoms/humming-while-driving/)；自动变速箱的类似情形
见
[自动变速箱啸叫的早期征兆](/zh/articles/automatic-transmission-whine-early-signs/)。

## 里面磨的是什么

通常有三样东西。第一是轴上的轴承：它们一直在工作，对过热和陈旧油品反
应最快。第二是某一个传动比的主、从动齿轮的齿面；这时候啸叫只在那一个
挡位里听得见，别的挡都安静。第三是主减速器和差速器：它们的啸叫频带更
宽，对给油还是滑行的反应更强烈。

还有一个单独的、很平淡的原因：油。油位低、黏度不对、或者早就超过更换
里程，都会让润滑变差，变速箱提前开始出声。查油位几乎不花钱，而且应该
排在任何重大决定之前。如果啸叫之外还添了挂挡打齿，那画面就变了——那种
情况见
[挂挡时打齿](/zh/articles/crunching-when-selecting-a-gear/)。

## 修理方案是怎么定的

均匀的啸叫，不带振动、不带杂乱敲击，并不需要立刻停车：带着它开很久的
人不少，有的开了好几年。要开始上心的信号是：出现轰鸣、顿挫、挂挡困难，
或者放油螺塞的磁铁上出现金属屑——到那个阶段，每多跑一千公里，修理就更
贵一分。

所以在拆开任何东西之前，决定取决于两项便宜的检查：变速箱油的油位和状
态，以及放油螺塞磁铁上的东西——细腻的灰色糊状物是正常磨损，一层竖起来
的金属屑就不是了。这两项加起来，就能把“换油再观察”和“准备大修”分开。

有两件事师傅不一定会说。如果变速箱必须落下来，那离合器套件要顺便一起
换——工时已经付过了，以后再够到它就得整活儿重来一遍。另外，齿轮油的规
格比品牌重要得多：变速箱油之间不能互换，摩擦改进剂不对，反而正好制造
出你想治的那种噪音。

如果啸叫很轻，你又拿不准它来自变速箱还是车轮，那就在最听得清的那个车
速上用 Pro-Stuk 应用录一段，再换个挡在同样车速下录一段。应用会把两段录音
和你的回答一起比对，按百分比给出可能的原因。
