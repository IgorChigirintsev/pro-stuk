ステアリングラックは操舵系の中心にある部品です。ハンドルの回転を
タイロッドの左右方向の動きに変え、路面からの衝撃をすべて受け止めます。
ラックが突然死ぬことはめったになく、その何か月も前からはっきりした
合図を送ってきます。それを読めると得をします。早い段階なら安価な調整で
片づき、遅れるとオーバーホールか新品交換になるからです。以下、サインの
一覧と簡単な確認、そして修理の決め方をまとめます。

## サインと、その意味

| サイン | 考えられる原因 | 緊急度 |
|---|---|---|
| 小さな段差での鈍い打音 | かみ合い部やブッシュのガタ | 数週間以内に点検 |
| 直進付近での遊び | ラックとピニオンの摩耗 | 数週間以内に点検 |
| 引っかかる、ハンドルが段階的に動く | ラックバーのかじり、締めすぎたヨーク | 数日以内に工場へ |
| 操舵が重い | フルード不足、ポンプやバルブの摩耗 | すぐ液面を確認 |
| ハンドルを切ると唸る | パワステポンプが空気を吸っている、摩耗 | すぐ液面を確認 |
| ブーツにオイルが回っている | 油圧ラックのシール漏れ | 修理。継ぎ足しは一時しのぎ |
| ハンドルが中立に戻らない | ヨークの締めすぎ、機構の固着 | 調整 |

いちばん多い初期サインは打音です。鈍く単発で、車体の中央寄りから
聞こえ、駐車状態でハンドルを小刻みに揺すれば簡単に再現できます。
路面から出るほかの打音とその発生源は症状ページ
[段差での打音](/ja/symptoms/knocking-over-bumps/)
にまとめてあります。

## 機構系と油圧系：二つの別々の筋書き

ラックは二本の独立した道筋で老いていきます。機構側はラックとピニオンの
摩耗、緩んだヨーク、傷んだサポートブッシュで、打音と遊びとして出ます。
油圧側は、パワーステアリング付きの車でシールとコントロールバルブが
摩耗する道です。フルードが漏れ、操舵が重くなり、ハンドルを切ると
ポンプが唸ります。その音については症状ページ
[旋回時の唸り音](/ja/symptoms/humming-when-turning/)
と
[ハンドルを切ったときのパワステの唸り](/ja/articles/power-steering-whine-when-turning/)
を参照してください。

どちらの道が壊れたのかを知ることには意味があります。油圧が健全な状態の
打音は調整で片づくことが多い一方、漏れが出ていれば必ずシール交換を伴う
オーバーホールになります。電動パワーステアリングの車には油圧がありま
せんが、その代わり独自の症状をもつ電子制御があります。
[電動パワステの不具合のサイン](/ja/articles/electric-power-steering-fault-signs/)
を参照してください。

## 自分でできるラックの確認

1. **遊びのテスト。** 駐車状態でエンジンをかけたまま、ハンドルを小さく
   左右に揺すります。リムのところで二、三センチを超える遊びがあり、
   鈍い打音を伴うなら、機構内にガタがあります。
2. **手を添えるテスト。** 誰かにハンドルを揺すってもらいながら、
   ラックのハウジングに手のひらを当てます。手に伝わる打撃は、どんな
   聴診よりも正確に部品を特定してくれます。タイロッドのジョイントの
   打音は別に感じ取れます。症状は
   [タイロッドの摩耗のサイン](/ja/articles/signs-of-worn-track-rod-ends/)
   と
   [タイロッド本体の摩耗のサイン](/ja/articles/signs-of-worn-tie-rods/)
   にあります。
3. **ブーツの目視。** 下からのぞき、ラック両端の蛇腹ブーツが乾いていて
   破れていないことを確かめます。湿っていたりオイルの膜があったりすれば、
   油圧が漏れています。
4. **液面の確認。** 油圧式の車ではリザーバーを見ます。地面に水たまりが
   ないのに液面が下がるなら、ラック内部への漏れで、フルードはブーツに
   溜まっています。

## 修理の決め方

道は三つ、調整、オーバーホール、交換です。選択は値段だけで決まるもの
ではありません。

調整は、ラックバーをピニオンに押し付けているヨークを締めることです。
摩耗が均一で程度も中くらいなら、これで打音は消えます。限界も正直な
ものです。締めすぎるとハンドルが中立に戻らなくなり、バーの摩耗も
早まります。工場でヨークを調整した結果ハンドルが重くなって戻ってきた
なら、それは新たな故障ではなく調整が限界に達したという意味です。

オーバーホールはシールとブッシュを新品にし、可能ならバーを研磨し直す
作業です。漏れへの答えであり、調整では吸収しきれなくなった遊びへの
答えでもあります。バー自体のかじりを点検したか聞いてください。かじった
バーのままオーバーホールしたラックは、一年でまた漏れます。

交換は、バーやハウジングが損傷しているときの答えです。電動アシストを
内蔵したラックでは、これが唯一の正規ルートであることも多くあります。

どの道を通っても、そのあとはアライメントです。タイロッドに触れる作業は
どれもトー角を変えます。そして油圧を減った状態で使っていたなら、
継ぎ足しではなくフルードの交換を頼んでください。古いフルードには、
シールを削った金属粉が入っています。

## 放置が高くつく理由

ラックが「急にハンドルが効かなくなる」ような破局を起こすことは、まず
ありません。衰えは何か月にもわたって進みます。本当のリスクは別の
ところにあります。バーの摩耗は深まり、今日なら調整で救える部品が半年後
にはオーバーホール行きになります。漏れはパワステポンプにとどめを刺し、
空気を吸って回るポンプがラックと道連れに死んで請求額は倍になります。
そして引っかかる操舵は安全に直結します。段階的にしか動かないハンドルは、
とっさの正確な操作を邪魔します。

今のところ手元にあるのが音だけで、本当にラックが原因か疑わしいなら、
荒れた路面を代表する区間でStukアプリに打音を録音してください。録音と
あなたの回答を突き合わせ、考えられる原因を割合つきで示します。仮説を
持っていけば、工場での診断も短く済みます。
