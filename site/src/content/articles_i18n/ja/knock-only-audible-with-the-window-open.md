まぎらわしい状況です。窓を上げていれば車はまったく健康に思えるのに、ガラス
を下ろした途端、速度に同期したはっきりとした打音、カチカチ音、ゴリゴリ音が
現れる。最初は気のせいかと思うでしょう。実際にはこれはごく普通の物理現象で、
しかも道具として使えます。外からしか聞こえないという事実そのものが、発生源
について何かを教えてくれるからです。

## なぜガラスはこの音だけを飲み込むのか

ボディは周波数ごとに室内への伝え方が違います。低いゴロゴロ音や振動は、金属、
サブフレーム、マウント類を通って伝わるので、密閉した車内でも聞こえます。
高い周波数の音、つまりカチカチ、キンキン、ゴリゴリ、コツコツは主に空気を
通って伝わり、ガラス、ウェザーストリップ、ドアの遮音材にきれいに吸収され
ます。窓を開けるとこの障壁がなくなり、音がまっすぐ届くわけです。

ここから実用的な結論が出ます。開けた窓越しにしか聞こえない不具合は、ほぼ
確実に高周波で、しかも車外にあります。ホイールハウスの中、ブレーキ機構、
排気系、フロア下。マウントを介してボディに載っている問題、つまりエンジン、
荷重のかかった足回り、トランスミッションは、たいてい窓を閉めていても聞こえ
ます。

## この鳴り方をするのは何か

| 発生源 | 音の性質 |
|---|---|
| ブレーキパッド摩耗インジケーター | 細い金属的な鳴き。ブレーキを踏むと止まる |
| ブレーキ機構への小石の噛み込み | タイヤ一回転につき一回のゴリッ。一〜二日で消えることも多い |
| アウター側ドライブシャフトジョイント | 深く曲がったときの乾いたカチカチ音。タイヤの回転と正確に同期 |
| ブレーキローターのダストカバー | 明るいカチカチ音。曲がった板金がローターに触れている |
| ハブベアリングの末期 | ゴーッ、ウーッといううなり。カーブで大きくなる |
| 排気系の緩み | ある回転数域で下から出るガタガタ音 |

この表の全項目に共通するのは、発生源がホイールハウスかフロア下にあること
です。ここは音が開いた窓へまっすぐ入っていく一方、ボディを介しては室内に
ほとんど届かない領域。だからいつもの「どこかで何かが鳴っている」よりも、
容疑者のリストは一気に短くなります。

これらの音には無害なものと、はっきりした警告であるものが混じっています。
ブレーキペダルを踏むと止まる金属的な鳴きは、機械式のパッド摩耗インジケー
ターが仕事をしている音です。詳しくは
[耳でブレーキパッドの摩耗を判断する](/ja/articles/brake-pad-wear-by-ear/)と
[ブレーキパッド摩耗インジケーターの音](/ja/articles/brake-pad-wear-indicator-sound/)
をご覧ください。カーブでの乾いたカチカチ音はアウター側ドライブシャフト
ジョイントで、
[円を描いて走るドライブシャフトの点検法](/ja/articles/checking-a-cv-joint-by-driving-circles/)
で確かめられます。

## 開けた窓を診断に使う

この手を、ちょっとした手順に落とし込んでおく価値があります。片側に壁か高い
フェンスが続く狭い道を見つけてください。反射した音が開けた窓に戻ってきて、
発生源が倍の明瞭さで聞こえます。その区間を20〜40km/hで、まず左の窓を下ろ
して、次に右の窓を下ろして走る。二回の走りの差が、どちら側かを教えてくれ
ます。

次に条件を変えます。同じ区間を惰性で、軽くアクセルを当てて、そしてブレーキ
ペダルに一度だけ触れて。ブレーキで消える音はブレーキ機構。タイヤの回転に
同期し、エンジン回転数とは無関係な音は足回り。速度とともに大きくなる均一な
うなりは、たいていベアリングです。段階ごとの進行は
[うなり始めてからハブベアリングはどれだけ保つか](/ja/articles/how-far-a-wheel-bearing-lasts-after-the-hum-starts/)
にまとめています。下から聞こえてブリキがガタつくような音なら、症状ページ
[車の下からのガタガタ音](/ja/symptoms/rattling-under-car/)と
[ガタつく遮熱板の見つけ方](/ja/articles/finding-a-rattling-heat-shield/)
を見てください。

## 緊急度と修理の決め方

原則は単純です。外からしか聞こえない音は、大きさではなく種類で判断します。
パッドのインジケーターの鳴きは、金属に達するまでの摩擦材が残り少ないという
意味なので、先延ばしにすべきではありません。ドライブシャフトのカチカチ音は
数週間は待てますが、数か月は待てません。ガタつく遮熱板なら、次の定期入庫
まで落ち着いて待てます。

作業内容を決めるのは、音の正体が何だったかであり、確認自体は安く済みます。
ブレーキ機構に噛んだ小石や曲がったダストカバーは、ホイールを外せば数分で
片づき、部品代はゼロです。排気系やカバーの締結部は増し締めするか、ゴム
ハンガーを一つ交換するだけ。本当に部品交換になるのは、パッド、ドライブ
シャフト、ベアリングくらいのものです。

整備士がいつも言うとは限らないことが二つ。一つ、インジケーターが鳴ったから
パッドを換えるなら、同時にローターの状態も聞いてください。インジケーターは
摩擦材のことしか警告してくれず、摩耗したローターは新品パッドでも同じ鳴きを
返してきます。二つ、キャリパーのスライドピンを分解してグリスを塗り直して
もらうこと。完全に戻りきらないキャリパーは、走行距離から想像するよりずっと
早くパッドをインジケーターまで削ります。
[ブレーキキャリパーの固着の点検方法](/ja/articles/how-to-check-a-brake-caliper-for-sticking/)
に手順があります。

この種の音を言葉で整備士に伝えるのは、ほぼ不可能です。ピットの上では車は
止まっていて、窓は開いていて、そもそも速度とコーナリングという組み合わせが
ありません。ですから窓を下ろして走った一区間をStukアプリで録音してください。
録音を解析し、速度や条件についての回答と突き合わせて、考えられる原因を確率
つきで示します。工場には、実際に聴かせられる音源を持ち込めます。
